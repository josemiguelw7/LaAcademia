# lilianamiranda.com — sitio de La Academia

Sitio estático basado en la plantilla Hayler (licencia ThemeForest de Jose Miguel), con colores Ónix y Bronce.
Sin build: Vercel sirve los archivos tal cual (ver `vercel.json`).

- `index.html` — inicio · `precios.html` — los tres niveles
- Personalización solo en `css/custom.css` (bloque «La Academia» al final), `css/variables.css` y `js/scripts.js`; el resto es núcleo de Hayler.
- El código anterior de la academia (Next.js + Supabase) está en la rama `academia-nextjs`.
- "Entrar" apunta a https://la-academia-eta.vercel.app/entrar — actualizar cuando la academia tenga su propio dominio.
- Precios escritos en el HTML ($497 / $897 / $1,497).
